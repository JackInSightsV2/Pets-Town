## What to build

Real project/parent relationships control areas, optional subagent visibility and readable overflow.

PetsTown observes existing Codex agents. Start the day controls presentation only; genuine ChatGPT/Codex pets are required.

## Acceptance criteria

- [x] One open-plan office retains stable project allocations; project identity remains available in the inspector. Visual area labels are intentionally removed by #33.
- [x] Both main and subagents show by default; a global toggle hides subagents without affecting their work.
- [x] Crowded groups collapse into expandable counts using stable parent identities.
- [x] Hidden agents with pending requests leave visible group attention and can be inspected.
- [x] Layout supports more than four projects; the background's four desk clusters are not a cap.
- [x] Joining/leaving agents and unknown parents do not duplicate or orphan pets.
