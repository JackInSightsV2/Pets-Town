# Launch the office webpage from Codex CLI

An Office launch action from Codex CLI opens a browser view, where Start the day triggers arrivals and standup. A separate webpage gives the hackathon control over the visual experience without depending on modifications to the ChatGPT/Codex desktop interface, while existing Codex agents continue their work independently. The user has delegated the choice of local app, skill and plugin packaging; a command like `/office` describes the desired convenience, while the implementation should use a supported invocation mechanism.
