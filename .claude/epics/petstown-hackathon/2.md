## What to build

Existing live agents become a presenter-controlled opening and then activity-driven pets in the office.

PetsTown observes existing Codex agents. Start the day controls presentation only; genuine ChatGPT/Codex pets are required.

## Acceptance criteria

- [x] Office opens ready; Start the day is the only automatic ceremony trigger.
- [x] Pets arrive individually, main pets give brief factual updates, subagents are summarized, and skip advances to live work.
- [x] Current events continue updating during the ceremony; neither it nor skip affects Codex work.
- [ ] Observed activity drives desks/quiet spots/sofas; verified completion celebrates then rests; closed sessions leave.
- [ ] A separate water-cooler prop and waypoint match the office style without generating pet characters.
- [ ] Geometry keeps pets on sensible paths; repeated Start clicks do not duplicate the ceremony or pets.
- [x] A small scene interface supports independent handoff choreography from S4 without requiring S4 to wait for visual polish.
