# Separate the demo ceremony from agent execution

PetsTown observes existing agents, with three agents prepared outside the office for the hackathon demo; it does not launch or orchestrate a new team. Start the day controls the arrival and standup presentation while real work continues, giving the presenter a predictable opening without taking ownership of agent execution. Live inspection and a real water-cooler handoff form the first demo checkpoint, followed by in-office replies, with voice and a live computer view reserved for later checkpoints.
