# Visualize existing Codex agents

PetsTown represents agents already working in Codex; Codex remains responsible for their work and execution. The agency and Munder Difflin references supply ideas for the visual office, rather than a new agency workflow or orchestration system. Arrivals, standups, pet visibility and other presentation choices do not gate the underlying work: work updates and unresolved attention indicators follow actual agent activity, while the activity connection and response mechanism remain open design questions.
