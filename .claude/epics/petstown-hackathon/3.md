## What to build

Selecting an existing pet opens its current task, recent visible activity and real pending request details.

PetsTown observes existing Codex agents. Start the day controls presentation only; genuine ChatGPT/Codex pets are required.

## Acceptance criteria

- [x] Selection uses stable agent identity and survives state changes.
- [x] The panel shows the correct agent, task and recent activity; missing facts are explicit.
- [ ] A real unresolved request creates !; clicking, fading and scene reset do not clear it.
- [ ] Resolution from the original Codex client updates the panel and clears the matching request only.
- [x] If only a waiting flag is observable, show details unavailable instead of inventing a prompt.
- [x] Distinguish agent failure from bridge disconnection and stale data.
- [x] Direct replies remain unavailable with an explanation until S7 proves that capability; Open chat is navigation only.
