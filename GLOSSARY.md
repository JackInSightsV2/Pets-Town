# PetsTown

PetsTown gives the user's existing Codex agents a shared visual office.

## Language

**Agent**:
An existing Codex worker performing the user's work, whose activity can be represented in PetsTown.
_Avoid_: Agency employee

**Main agent**:
An agent in a Codex conversation the user works with directly, which may have subagents helping it.

**Subagent**:
An agent spawned to carry out work for another agent.

**Pet**:
The animated ChatGPT/Codex pet representing an existing Codex agent in the office.
_Avoid_: Separate worker, autonomous employee

**Office**:
The shared visual area where pets appear and make their agents' activity visible.
_Avoid_: Agency

**Office launch**:
The user's invocation that opens the office experience, ready for the presenter to start its visual sequence.

**Start the day**:
The presenter's action that begins the pets' arrival and standup sequence while their existing agents continue working.
_Avoid_: Start agents, assign work

**Project area**:
A part of the shared office occupied by pets working on the same Codex project.
_Avoid_: Room, separate office

**Subagent group**:
The subagents belonging to a main agent, which can be represented together when their project area is crowded.

**Standup**:
A brief visual gathering after Start the day where main pets give factual updates with personality and summarize their subagents while the actual work continues.
_Avoid_: Work gate

**Work location**:
A spot within the office, such as a desk, quiet corner or sofa, where a pet appears according to its agent's activity.

**Help request**:
A real request from an agent for input or action from the user.
_Avoid_: Routine status update

**Attention indicator**:
The `!` marking a pet whose agent has an unresolved help request.
_Avoid_: Status bubble

**Pet detail panel**:
The view of a selected pet's task, recent agent activity and outstanding question, where the user can help its agent.

**Handoff**:
A real transfer of work or information between two agents, represented by their pets meeting at the water cooler.
_Avoid_: Decorative meeting, invented collaboration

**Demo cohort**:
The three existing agents prepared for the presentation, without restricting the office's ability to display other active agents.

**Office session**:
One presentation of the shared office, whose arrivals, standup and reset are independent of the underlying agents' work.
