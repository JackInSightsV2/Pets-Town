# Activity reader integration

For Windows, the opt-in adapter `src/codex/activity/windows-adapter.ts` uses the existing rollout file/root and allowed-directory environment variables. Launch with `npm run office -- --adapter ./src/codex/activity/windows-adapter.ts` and the same `PETSTOWN_ROLLOUT_FILES` or `PETSTOWN_ROLLOUT_ROOT` and `PETSTOWN_METADATA_CWDS` settings as the rollout observer. Only new completed or failed command records with matching session and turn identities are shown as recent activity. Historical and partial initial lines are seeded silently. This does not indicate current work or completion of an agent's task.

The reader stages only fixed structural fields and releases a batch after file and duplicate-identity validation. The adapter applies directory scope before normalizing, and publishes recent activity only after the corresponding scoped metadata poll completes.

Keep the normalizer or its checkpoint across reconnects. Seed historical records before live records, including a partial initial line when it is eventually completed. A capacity or conflicting-source result must fail closed, not clear the checkpoint. The source namespace must be stable across reconnects and distinguish independent runtimes; it must not be a path or bridge epoch. A rollout reader must associate the record with its file's verified session, not trust a supplied path or transcript content. The existing reader's initial byte boundary provides the history classification.

For app-server notifications, use the notification's verified thread and turn IDs and deliver `item/completed` notifications through the same instance. Do not send raw observations, correlation inputs, or checkpoints to the client. Output summaries are fixed; `sourceItemId` is deliberately null. Only command executions with completed or failed status are supported. Other tool types, reading, searching, editing, pending requests, work completion and handoffs are not inferred. The adapter must arrange a stable public agent ID and avoid emitting events for agents outside its scope.
